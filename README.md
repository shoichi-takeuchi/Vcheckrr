# 秀丸メール フィッシング検知システム

秀丸メールで受信したメールを自動監視し、フィッシングメールの疑いがある場合にWindowsポップアップ通知で警告するシステムです。

---

## 機能

- **常駐監視**: `D:\TuruKameData` フォルダを監視し、新着メールをリアルタイムで検知
- **スコアリング検知**: キーワード・URL・送信者・なりすまし表示名など多角的に分析
- **英日両対応**: 日本語・英語のフィッシングメールをどちらも検知
- **メール認証チェック**: SPF / DKIM / DMARC の失敗を自動検知
- **Reply-To 不一致検知**: 返信先が送信元と異なるなりすましを検知
- **HTMLパターン検知**: 非表示テキスト・偽フォーム・data:URI リンクなどを検知
- **ポップアップ警告**: Windowsトースト通知＋詳細ダイアログで視覚的に警告
- **重複通知防止**: 同じメールへの通知を5分間抑制し、誤動作を防止
- **GitHub自動更新**: 検知ルール（JSONファイル）をGitHubから自動更新
- **ログ記録**: 検知結果を `logs/phishing_detect.log` に保存（自動ローテーション）

## セットアップ手順

### 1. パッケージのインストール

`install.bat` をダブルクリックして実行します。

または手動でコマンドプロンプトから：
```
cd デスクトップ\Python_code\08_Vcheck
pip install -r requirements.txt
```

### 2. 設定ファイルの確認

`config.json` を開いて以下の項目を確認します：

```json
{
  "paths": {
    "mail_data_dir": "D:\\TuruKameData"  ← メールデータの場所（変更不要）
  },
  "update": {
    "github_repo": "shoichi-takeuchi/Vcheckrr"  ← 設定済み
  }
}
```

### 3. 起動

- **通常起動（コンソール表示）**: `start.bat` をダブルクリック
- **バックグラウンド起動**: `start_hidden.vbs` をダブルクリック
- **PC起動時に自動起動**: Windowsタスクスケジューラに登録済み（`VCheck_PhishingDetector`）
  - ログオン時に自動起動 → GitHubから最新ルールを取得 → 監視開始

### 4. 停止

`stop.bat` を実行するか、起動したコンソールで `Ctrl+C` を押します。

## 使用方法

### 通常の使い方

起動したまま放置するだけです。新着メールが届くと自動的にチェックし、フィッシングの疑いがある場合は右下にポップアップ通知が表示されます。

### 警告レベル

| レベル | スコア | 色 | 意味 |
|--------|--------|-----|------|
| **危険** | 60以上 | 赤 | フィッシングの可能性が高い。絶対にリンクをクリックしないこと |
| **警告** | 30〜59 | オレンジ | 注意が必要。送信元を確認する |
| **安全** | 30未満 | なし | 通知なし |

> スコアの最大値は200点です。

### 詳細ダイアログ

危険スコアが60以上の場合、詳細ダイアログが自動表示されます：
- 検知されたリスクの理由一覧
- 不審なURL
- 送信者情報

## 検知項目（スコアリング）

| 検知項目 | スコア | 説明 |
|----------|--------|------|
| 件名・本文の危険キーワード（日本語） | +30 / ヒット | アカウント停止・不正アクセスなど |
| 件名・本文の注意キーワード（日本語） | +10 / ヒット | 確認要求・期限切れなど |
| 件名・本文の危険キーワード（英語） | +30 / ヒット | account suspended / verify your account など |
| IPアドレスURL | +40 | 数字のみのURLは偽サイトの典型 |
| フィッシングドメインパターン | +45 | arnazon / amaz0n などのタイポスクワット |
| なりすまし表示名 | +35 | Amazon 等の表示名で別ドメインから送信 |
| **Reply-To 不一致** ★新機能 | +25 | 返信先が送信元ドメインと異なる |
| **SPF 認証失敗** ★新機能 | +20 | メールサーバーが正規でないことを示す |
| **DKIM 署名失敗** ★新機能 | +20 | メール内容が改ざんされた可能性 |
| **DMARC ポリシー違反** ★新機能 | +25 | ドメイン所有者のポリシー違反 |
| 不審なTLD (.xyz/.top など) | +20 | 悪用されやすいドメイン拡張子 |
| URLショートナー | +15 | リンク先を隠蔽するサービス |
| 無料ホスティング | +25 | フィッシングページに悪用されやすい |
| **非表示テキスト** ★新機能 | +15 | スパムフィルタを欺くための隠しテキスト |
| **偽フォーム (HTTP送信)** ★新機能 | +20 | 暗号化なしのフォーム送信先 |
| **data: URI リンク** ★新機能 | +30 | URLを隠すBase64偽装リンク |
| 緊急性フレーズ | +10 | 「今すぐ」「本日中に」など焦りを煽る表現 |
| 報酬フレーズ | +15 | 「当選しました」「無料プレゼント」など |

## 自動更新（GitHub連携）

検知ルール（keywords.json / domains.json / patterns.json）をGitHubから自動更新できます。

### 設定手順

1. GitHub リポジトリ: https://github.com/shoichi-takeuchi/Vcheckrr
2. `rules/` フォルダの3つのJSONファイルを編集・更新するだけで自動反映
3. 次回PC起動時（または24時間ごと）に自動チェック・ダウンロード

### 強制更新

```
python main.py --update
```

## ホワイトリスト設定

信頼できる送信者をホワイトリストに登録すると、検知対象から除外できます。

`config.json` の `whitelist` セクションを編集：

```json
"whitelist": {
  "enabled": true,
  "senders": ["boss@example.com", "newsletter@trusted.com"],
  "domains": ["trusted-company.co.jp"],
  "subjects_containing": ["社内連絡"]
}
```

## ログの確認

検知されたメールの記録は `logs/phishing_detect.log` に保存されます。
ログは **最大5MB × 5世代** で自動ローテーションされます。

各行はJSON形式です：
```json
{
  "timestamp": "2026-05-25 10:30:00",
  "risk_level": "danger",
  "score": 85,
  "subject": "【緊急】アカウント停止のお知らせ",
  "from_address": "support@amaz0n-co-jp.xyz",
  "reasons": ["なりすまし疑い: ...", "件名に危険なキーワード: ...", "SPF 認証失敗: FAIL"],
  "suspicious_urls": ["http://192.168.1.1/login"]
}
```

## ESET連携について

現在はESETとの直接連携は無効になっています（`config.json` の `eset.integration_enabled: false`）。

ESETがフィッシングサイトをブロックした場合でも、このシステムが事前にメール段階で警告を出すことで二重の防御になります。

## トラブルシューティング

**通知が表示されない**
- Windowsの通知設定で「通知とアクション」→「アプリからの通知」が有効になっているか確認

**メールが検知されない**
- `config.json` の `paths.mail_data_dir` が正しいか確認
- 秀丸メールのデータ保存先が `D:\TuruKameData` であるか確認

**起動エラーが出る**
- `install.bat` を再実行してパッケージをインストール
- `python --version` でPython 3.8以上であることを確認

**誤検知が多い**
- `config.json` の `whitelist` に信頼できる送信者を追加
- `rules/patterns.json` の `scoring` でスコアの閾値を調整
